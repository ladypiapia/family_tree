# 家族族谱助手（PRD版）

按 `PRD.md` 从零重建，技术栈：React + TypeScript + Vite + Tailwind CSS + React Flow + idb。

## 已实现能力

- 多家族管理：创建、切换、删除家族
- 成员管理：新增/编辑/删除、头像上传（Base64）、出生日期、在世状态、备注
- 关系管理：父母、配偶/伴侣、兄弟姐妹
- 添加成员时关系绑定：可直接与现有成员建立关系
- 族谱可视化：React Flow 画布，支持拖拽、缩放、小地图
- 中心视角：切换任意成员为中心，并自动更新其他成员称呼标注
- 称呼查询器：任意两人关系推断 + 路径展示
- 称呼覆盖：支持为“成员A -> 成员B”设置自定义称呼
- 本地存储：idb + LocalStorage 回退
- 数据导入导出：JSON

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端输出地址即可。
